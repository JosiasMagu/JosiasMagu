## Projectos

**[ZUNO (backend)](https://github.com/JosiasMagu/Zuno_back)**
Plataforma de aluguer de equipamentos e serviços, feita para um cliente. O valor fica retido na plataforma até o cliente confirmar a entrega, e cada movimento de dinheiro fica num registo que não se altera. O pagamento por M-Pesa ainda não está ligado e, nesta fase, quem confirma o pagamento é um administrador. Sou o responsável pelo backend, numa equipa de 3.
NestJS 11, Prisma, PostgreSQL, Socket.IO, Cloudinary, Docker. Mais de 1500 testes unitários e 600 de ponta a ponta, corridos no GitHub Actions.
